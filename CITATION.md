## 🔗 Citation Formats

### **APA Format** (Recommended for academic papers)
```
Paudel, A. (2024). OpenSeesPy Tutorials: Python examples for structural dynamics 
and earthquake engineering [Computer software]. GitHub. 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials
```

### **BibTeX Format** (For LaTeX documents)
```bibtex
@misc{paudel2024openseespytutorials,
  author = {Paudel, Ashim},
  title = {OpenSeesPy Tutorials: {P}ython Examples for Structural Dynamics and Earthquake Engineering},
  year = {2024},
  howpublished = {GitHub Repository},
  url = {https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials}
}
```

### **Chicago Manual of Style Format**
```
Paudel, Ashim. "OpenSeesPy Tutorials: Python Examples for Structural Dynamics 
and Earthquake Engineering." GitHub Repository. Accessed [date accessed]. 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials.
```

### **MLA Format**
```
Paudel, Ashim. OpenSeesPy Tutorials: Python Examples for Structural Dynamics 
and Earthquake Engineering. GitHub, 2024, https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials.
```

### **Harvard Format**
```
Paudel, A., 2024. OpenSeesPy Tutorials: Python examples for structural dynamics 
and earthquake engineering. [online] Available at: 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials [Accessed date].
```

### **IEEE Format**
```
[1] A. Paudel, "OpenSeesPy Tutorials: Python examples for structural dynamics 
and earthquake engineering," GitHub, 2024. [Online]. Available: 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials. [Accessed: date].
```

### **Simple Text Citation**
```
Paudel, A. (2024). OpenSeesPy Tutorials. Retrieved from 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials
```

## 📚 Citation by Use Case

### **Using Entire Repository**
Use the full citation from your preferred format above.

### **Using Specific Examples or Modules**
Specify the module in your citation:

**APA:**
```
Paudel, A. (2024). Fiber section of RCC section [Jupyter Notebook]. In OpenSeesPy 
Tutorials: Python examples for structural dynamics and earthquake engineering. GitHub. 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials
```

**BibTeX:**
```bibtex
@misc{paudel2024fibersection,
  author = {Paudel, Ashim},
  title = {Fiber Section of {RCC} Section},
  year = {2024},
  booktitle = {OpenSeesPy Tutorials},
  howpublished = {GitHub Repository},
  url = {https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials}
}
```

### **Using Helper Functions**
If you adapt or extend code from the helper functions:

**APA:**
```
Adapted from Paudel (2024), specifically the modelFunctions.py module. Retrieved from 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials
```

**In-text:**
```
"The automated building generation approach follows Paudel (2024), using the getModel() 
function from OpenSeesPy Tutorials."
```

### **Using in Thesis/Dissertation**
Add to references section and cite throughout your document:

**Footnote/Endnote:**
```
Paudel, Ashim. OpenSeesPy Tutorials: Python Examples for Structural Dynamics 
and Earthquake Engineering. GitHub Repository, 2024. 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials.
```

### **Using in Research Paper**
Include in References section:

```
Paudel, A., 2024. OpenSeesPy Tutorials: Python examples for structural dynamics 
and earthquake engineering. GitHub Repository. Available at: 
https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials (Accessed [date]).
```

### **Using in Code/Software Project**
Add a comment in your code:

```python
# Based on OpenSeesPy Tutorials (Paudel, 2024)
# https://github.com/Ashim-Paudel/OpenSeesPy-Tutorials
# Adapted from: [specific module/example]

# Original function reference:
# Paudel, A. (2024). buildFiberSection.py. OpenSeesPy Tutorials.
```

## 🏷️ Citation Tools

### **Cite This Repository Directly**

Many platforms generate citations automatically:

1. **GitHub**: Click "Cite this repository" in the About section
2. **Zenodo**: Repository may be archived with DOI (if available)
3. **Zotero**: Import directly into Zotero reference manager
4. **Mendeley**: Add via URL or import metadata

### **For Your Reference Manager**

**Zotero:**
- Manual Entry: Type as Software
- Fields: Creator, Title, URL, Date, Publisher (GitHub)

**Mendeley/Reference Manager:**
- Import as Website or Generic Document
- Manually adjust document type to Software

## 📝 If You're Writing an Academic Paper

### Required Elements in Your Paper:

1. **In-text citation** (every time you reference the work)
   ```
   "...following the methodology presented by Paudel (2024)..."
   ```

2. **Bibliography/References entry** (full citation)
   ```
   [Use one of the formats above]
   ```

3. **Acknowledgments section** (if significant use)
   ```
   "The authors acknowledge the OpenSees Learning Resources (Paudel, 2024) 
   for [specific contribution]."
   ```

### Example Sentences:

```
"The fiber section discretization approach implemented in this study follows 
Paudel (2024), using automated section builder functions to improve modeling efficiency."

"Time-history analysis was conducted using procedures documented in Paudel (2024), 
including earthquake record integration and ground motion scaling."

"Modal analysis was performed following the eigen analysis methodology presented 
in the OpenSees Learning Resources (Paudel, 2024)."
```

## 🙋 Questions About Citation?

If you're unsure about how to cite:

1. **Check your institution's citation guidelines** (they may have specific formats)
2. **Look at similar papers** in your field to see how they cite software
3. **Use citation generators** that accept GitHub URLs
4. **Err on the side of more attribution** - it's better to over-cite than under-cite
