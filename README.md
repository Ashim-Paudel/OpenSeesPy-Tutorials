Welcome to a comprehensive learning resource for **OpenSees with Python**! 

This repository contains educational examples and utilities for structural dynamics and earthquake engineering. Perfect for **beginners to researchers**.

## 📚 What's Included

**12 Learning Modules:**
- **00**: Structural Dynamics Fundamentals (A.K. Chopra examples)
- **01**: Basic Truss Analysis
- **02**: Fiber Section of RCC
- **03**: Moment Curvature Analysis
- **04**: Eigen Analysis of 2D Framed Buildings
- **05-06**: Cantilever Column Analysis (Elastic & Nonlinear)
- **07**: Portal Frame Analysis
- **08-09**: Pushover Analysis (Monotonic & Cyclic)
- **10**: Complete 2-Story Frame Analysis
- **11**: Helper Functions & Utilities
- **Theories**: Theoretical Foundations

**Helper Utilities:**
- Unit conversion (SI, Imperial, mixed systems)
- Automated building generation
- Fiber section builders (RC and Steel)
- Analysis automation functions
